# 设备型号映射与更新指南

PrivateDrop 前端支持自动探测移动设备并显示友好的商业机型名称（例如将 `RMX3800` 识别为 `Realme 真我GT6`，`SM-S9280` 识别为 `Samsung Galaxy S24 Ultra`）。

---

## 架构与原理

1. **探测机制**：
   - 安卓端基于 **User-Agent Client Hints (UA-CH)** 异步读取 `model`。
   - 前端通过 Vite `import()` 动态懒加载 `frontend/src/lib/android-models.json` 映射字典。
   - PC / iOS 端访问时**不会下载**该字典，0 首屏性能影响。
2. **数据来源**：
   - **Google Play 认证设备官方清单**（5 万+ 记录）：`http://storage.googleapis.com/play_public/supported_devices.csv`
   - **国内主流特供机型字典（内置补充）**：覆盖未搭载 GMS 的华为、小米、OPPO、vivo、荣耀、一加等热门机型。

---

## 如何更新机型映射库

当市场上有新手机发布或需要扩充机型映射时，只需在项目根目录下运行更新脚本：

```bash
# 运行数据生成与更新脚本
python3 scripts/generate_android_models.py
```

或者在 `frontend/` 目录下运行：

```bash
cd frontend
npm run update:models
```

### 脚本处理流程
1. 自动从 Google Play 官方下载最新 CSV 数据源。
2. 进行编码规范化、去重、品牌名称大小写美化。
3. 合并 `scripts/generate_android_models.py` 中定义的 `MANUAL_OVERRIDES` 自定义机型表。
4. 输出紧凑的 JSON 文件至 `frontend/src/lib/android-models.json`。

---

## 手动添加特定机型

如果发现某些小众机型或最新发布的国内机型在 Google Play 列表中未收录，可以直接在 `scripts/generate_android_models.py` 的 `MANUAL_OVERRIDES` 字典中添加：

```python
MANUAL_OVERRIDES = {
    # 格式："机型硬件代号": "展示名称"
    "RMX3800": "Realme 真我GT6",
    "RMX3700": "Realme GT Neo5 SE",
    "PJD110": "OnePlus 12",
    # ...
}
```

添加后重新运行 `python3 scripts/generate_android_models.py` 并执行 `npm run build` 即可生效。
